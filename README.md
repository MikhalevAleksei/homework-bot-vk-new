# homework_bot-vk

VK-бот, который раз в 10 минут спрашивает API сервиса Практикум Домашка о
статусе вашей домашней работы и присылает сообщение в VK, когда статус
меняется: работа взята на ревью, принята или возвращена на доработку.

О сбоях бот тоже пишет в VK, но одну и ту же ошибку присылает только один раз.
Все события записываются в лог: в стандартный вывод и в файл
`homework.py.log` рядом с `homework.py`.

## Как запустить

1. Клонируйте репозиторий и перейдите в его папку.
2. Создайте и активируйте виртуальное окружение, установите зависимости:

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Создайте в корне проекта файл `.env` (он уже есть в `.gitignore`):

   ```
   PRACTICUM_TOKEN=<токен API Практикум Домашки>
   VK_TOKEN=<ключ доступа сообщества VK с правом на сообщения>
   VK_USER_ID=<ваш числовой id в VK>
   ```

   Чтобы бот мог писать вам, сначала сами напишите сообществу в личные
   сообщения.

4. Запустите бота:

   ```bash
   python homework.py
   ```

Если какой-то переменной в `.env` нет, бот пишет об этом в лог с уровнем
CRITICAL и останавливается.

## Как устроен код

- `check_tokens()` — проверяет, что заданы все переменные окружения;
- `get_api_answer()` — запрашивает статусы домашек с момента `from_date`;
- `check_response()` — проверяет, что ответ API соответствует документации;
- `parse_status()` — готовит текст сообщения по статусу работы;
- `send_message()` — отправляет сообщение в VK;
- `main()` — повторяет цикл «запрос → проверка → сообщение» раз в 10 минут.

Свои исключения лежат в `exceptions.py`.

## Стек

Python 3, requests, vk_api, python-dotenv.
